# Echo Lu — Portfolio

Static portfolio website with HTML, CSS, JavaScript, and included image, video, font, and PDF assets. No installation or build step is required.

## Upload to GitHub

1. Unzip this archive.
2. Open your `echo-portfolio` repository on GitHub.
3. Choose **Add file → Upload files**.
4. Upload all the extracted files and the `assets` folder to the repository root. Keep their folder structure. Do not upload the ZIP itself.
5. Commit the changes.

## Publish with GitHub Pages

Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

For the `jillin09/echo-portfolio` repository, the default URL is:
https://jillin09.github.io/echo-portfolio/

## Preview locally

From the extracted folder, run:

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Pages

- `index.html` — Home
- `about.html` — About
- `lumi.html` — Lumi AI
- `voiceout.html` — VoiceOut
- `megaputer.html` — Insight-D Dashboard
